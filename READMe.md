# Arcane Angler Tracker

Track the grind, share the data, question your luck — when yh? 🎣

## Supported Browsers

Tested on Chrome and Brave. Should work on Edge, Opera or Vivaldi also.

## Installation

1. Download the latest ZIP from Releases.
2. Extract the ZIP.
3. Open your browser Extensions page.
4. Enable Developer Mode.
5. Click **Load unpacked**.
6. Select the extracted extension folder.
7. Open or refresh Arcane Angler.

## What It Tracks

### Session Tracker
Each session gives you a live overview of your fishing run, including:

- Session time and progress
- Manual, auto and total casts
- XP and levels gained
- Gold earned from casts and treasure chests
- Relics found
- Treasure chest rate
- Collectibles found
- Fish by rarity
- Gear by rarity
- Casts by weather
- Current biome and weather
- User ID and username

### Excel Data
Excel exports store the detailed data behind every cast, so you can analyse or merge sessions later.

Each cast can include:

- Local time and UTC time
- Manual or auto cast
- Biome and weather
- Fish name, rarity and count
- Bait used
- Equipped rod and rod level
- Total STR / INT / LUCK / STAM
- XP, gold and relics gained
- Treasure chest and collectible results
- Gear drops
- Guild XP and Treasure Totem levels
- Knowledge Scroll, Ancient Tome and Guild Booster status
- Session number and Session UID
- User ID and username

Multiple exported files can also be merged while keeping duplicate sessions separated correctly.
